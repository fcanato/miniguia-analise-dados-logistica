# 📊 Miniguia de Estudos — Análise de Dados Aplicada à Logística

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de explorar o uso da Inteligência Artificial como ferramenta de apoio à aprendizagem, utilizando o **NotebookLM** para organizar fontes, analisar conteúdos e construir um miniguia de estudos.

O tema escolhido foi **Análise de Dados Aplicada à Logística e Gestão de Estoques**, área em que a utilização de dados pode contribuir diretamente para a melhoria dos processos operacionais e para uma tomada de decisão mais eficiente.

Durante o desenvolvimento do projeto, serão utilizadas fontes abertas em texto ou PDF, que serão adicionadas ao NotebookLM. A partir dessas fontes, serão elaborados e testados diferentes prompts para identificar conceitos, gerar resumos, comparar informações e transformar conhecimento teórico em aplicações práticas.

Além do resultado final, o projeto também documentará as dificuldades encontradas, ajustes realizados nos prompts e estratégias utilizadas para melhorar a qualidade das respostas geradas pela Inteligência Artificial.

---

## 🎯 Objetivos de Estudo

Os principais objetivos deste projeto são:

* Compreender como a análise de dados pode apoiar processos logísticos;
* Estudar os principais conceitos relacionados à gestão de estoques;
* Compreender indicadores como acuracidade, giro e cobertura de estoque;
* Explorar métodos para identificação de excesso de estoque e risco de ruptura;
* Entender como dados históricos de consumo podem apoiar decisões de reposição;
* Utilizar o NotebookLM para análise e consolidação de diferentes fontes de conhecimento;
* Desenvolver técnicas de Engenharia de Prompts;
* Criar prompts reutilizáveis para futuras consultas e revisões;
* Documentar erros, dificuldades e melhorias realizadas durante as interações com a IA.
